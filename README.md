# VONETIS

Platform layanan jasa akademik & kreatif terpercaya #1 di Indonesia yang dibangun menggunakan **Next.js 16 (App Router)** dan **React 19**.

---

## 🛠️ Menjalankan Secara Lokal

```bash
npm install
npm run dev
```

Buka [http://localhost:3000](http://localhost:3000) di browser Anda.

---

## 🌐 Panduan Deploy di Vercel

1. Buka [Vercel Dashboard](https://vercel.com/new).
2. Import repository **`VONETIS`**.
3. Klik **Deploy** (langsung otomatis terdeteksi sebagai Next.js)!
